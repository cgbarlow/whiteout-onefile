# WHITEOUT source

The full source of the game in `../../index.html`. Everything (geometry, textures, lighting, sound) is generated by this code
at load time; the build bundles it into one self-contained HTML file.

## Build

Requires Node.js 18 or newer.

```bash
npm i
node build.mjs          # → dist/index.html (single file, fails if it goes over 2 MB)
```

`node build.mjs --readable` writes an unminified build (GLSL untouched) for debugging. Open `dist/index.html` through a local
server (`node tools/serve.mjs dist`) in desktop Chrome on a machine with a hardware GPU.

## Layout

| Path | What it is |
|---|---|
| `src/main.js` | boot order: engine, lighting, materials, station, terrain, generators, stalker, flashlight, weather, post, audio, game, HUD |
| `src/art.js`, `src/contracts.js` | art direction constants; camera poses, station layout, player and rule tuning |
| `src/modules/` | the game: `station/`, `terrain/`, `generators/`, `stalker/`, `flashlight/`, `atmosphere/`, `audio/`, `game/`, `hud/` |
| `src/look/` | WHITEOUT's material, surface and post tuning on top of the cookbook |
| `src/cookbook/` | the skill's shared rendering cookbook (engine, post chain, lighting, materials, geometry kit, weather, audio) |
| `src/ui/ui.css`, `template.html` | HUD and menus; the HTML shell the build injects the bundle into |
| `build.mjs`, `glsl-min.mjs` | esbuild single-file build and the GLSL minifier |
| `tools/` | real-GPU capture, benchmark, playtest bot, size report, contact sheets (Playwright + Chrome) |
| `playtest.json` | the bot script that plays to both the win and the lose screen: `node tools/playtest.mjs --url dist/index.html --script playtest.json` |
